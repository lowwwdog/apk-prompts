# АПК — библиотека промптов

40 прикладных кейсов и 120 готовых промптов для ChatGPT, Codex и Claude Code.

**Открыть сайт: https://apk-prompts.vercel.app**

## Использование

Откройте сайт или локальный `index.html`, найдите кейс, выберите сервис и скопируйте промпт. Замените поля в квадратных скобках и приложите указанные материалы.

В папке `prompts/` находятся полный сборник и отдельные подборки для каждого сервиса.

## Содержание

Письма, презентации, протоколы, анализ таблиц, финансовые модели, 1С и ERP, корпоративные помощники, обучение, маркетинг и другие задачи. Каждый промпт включает входные данные, ожидаемый результат и критерии проверки.

## Ограничения

Сборник подготовлен по 97 записям таблицы проекта 19 сентября 2026 года. Неоднозначные формулировки отмечены в материалах. Промпты не тестировались на реальных рабочих данных во всех трёх сервисах. Возможности зависят от инструментов и прав доступа конкретной среды.

## Развёртывание

Статический сайт без сборки и зависимостей. Для Vercel используется `vercel.json`.

# АПК — библиотека промптов

40 прикладных кейсов и 120 готовых промптов для ChatGPT, Codex и Claude Code.

**Открыть сайт: https://apk-prompts.vercel.app**

## Использование

Откройте сайт или локальный `index.html`, найдите кейс через поиск или один из пяти тематических кластеров, выберите сервис и скопируйте промпт. В поле «Результат» выберите: самостоятельное выполнение, внедрение в организации, MVP через вайбкодинг — либо оставьте «Помочь выбрать путь». Замените поля в квадратных скобках и приложите указанные материалы.

В папке `prompts/` находятся полный сборник и отдельные подборки для каждого сервиса.

## Содержание

Пять кластеров: документы и знания; данные и аналитика; коммуникации и контент; процессы и интеграции; специальные решения АПК. Каждый промпт включает входные данные, ожидаемый результат и критерии проверки.

## Ограничения

Сборник подготовлен по 97 записям таблицы проекта 19 сентября 2026 года. Неоднозначные формулировки отмечены в материалах. Промпты не тестировались на реальных рабочих данных во всех трёх сервисах. Возможности зависят от инструментов и прав доступа конкретной среды.

## Развёртывание

Статический сайт без сборки и зависимостей. Для Vercel используется `vercel.json`.

## Прототип единого портала

В папке [`portal/`](portal/) находится локальный React-прототип единого портала «ИИ × АПК». Он объединяет библиотеку кейсов, рабочую тетрадь, маршрут внедрения в организации, заметки сессии и методичку для скачивания.

Чтобы запустить его локально, перейдите в `portal/`, выполните `npm ci` и `npm run dev`. Подробности — в [`portal/README.md`](portal/README.md). Эта версия сохранена в ветке `portal-prototype` и не меняет опубликованный статический сайт.

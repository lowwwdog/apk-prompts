# ИИ × АПК — локальный прототип портала

Единая точка входа для кейсов, рабочей тетради, внедрения в организации и материалов сессии АПК.

## Запуск

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 4174
```

Откройте `http://localhost:4174`.

## Что внутри

- `/` — главная портала и маршруты работы;
- `/cases/` — каталог кейсов с кластерами и выбором способа реализации;
- `/workbook.html` — исходная рабочая тетрадь;
- `/implementation` — паспорт пилота для внедрения в организации;
- `/knowledge` — материалы и конспекты сессии;
- `public/downloads/` — методичка «Внедрение ИИ на производстве» для прямого скачивания.

## Проверка сборки

```bash
npm run build
```

Это локальный прототип: он не отправлен в GitHub и ждёт согласования перед публикацией.

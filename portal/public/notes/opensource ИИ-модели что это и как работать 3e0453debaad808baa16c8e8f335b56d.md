# opensource ИИ-модели: что это и как работать

### Общее про опенсорс

> **Опенсорс** — это программы с открытым исходным кодом: их можно изучать, дорабатывать и запускать самостоятельно в рамках лицензии.
>
>
> В ИИ часто используют более широкий термин — **модели с открытыми весами**. Их можно скачать и запустить на своём компьютере или сервере. Hugging Face — одна из крупнейших платформ, где публикуют такие модели.
>
> Для удобного локального запуска можно использовать [Ollama](https://ollama.com/). Это программа, которая скачивает выбранную модель и запускает её на компьютере. Например, через Ollama можно работать с китайскими моделями Qwen и DeepSeek.
>

**Зачем нужны локальные модели**

Локальная модель выполняет запросы не в облаке внешнего сервиса, а на вашем ноутбуке или в инфраструктуре компании. Её можно использовать без постоянного доступа к интернету, подключать к внутренним документам и встраивать в рабочие процессы.

**Преимущества**

- **Конфиденциальность.** Рабочие данные не нужно отправлять во внешний чат-бот: это важно для договоров, финансовых документов, персональных данных, технологических карт и внутренних отчётов.
- **Контроль.** Компания сама определяет, какие документы доступны модели, кто может ею пользоваться и где хранятся логи запросов.
- **Независимость.** Работа не зависит от доступности конкретного облачного сервиса, изменений тарифов или ограничений доступа.
- **Настройка под задачу.** Модель можно подключить к внутренней базе знаний, регламентам, справочникам и документам предприятия.
- **Предсказуемые расходы.** Нет платы за каждый запрос к внешней модели, хотя остаются затраты на компьютер или сервер, настройку и поддержку.

**Почему это может быть безопаснее**

При локальном запуске запросы и файлы остаются в выбранном контуре: на рабочем компьютере, закрытом сервере или в частном облаке компании. Их не требуется передавать публичному внешнему ИИ-сервису, поэтому риск утечки снижается.

При этом локальная модель не становится безопасной автоматически. Нужны права доступа, защита устройств и серверов, контроль того, какие документы ей подключены, а также проверка лицензии конкретной модели. Важные решения и результаты анализа всегда должен проверять человек.

**Примеры для АПК-компаний**

Локальная модель может:

- искать ответы в регламентах, инструкциях и технологических картах;
- кратко сводить отчёты агрономов, ветеринаров и руководителей хозяйств;
- помогать готовить черновики заявок, писем, актов и отчётов;
- отвечать сотрудникам по внутренней базе знаний;
- анализировать текстовые записи из полевых журналов, обращения клиентов и сервисные заявки.

**Примеры для личного использования**

- приватный помощник по личным заметкам, документам и архиву;
- краткие выжимки из локальных PDF, конспектов и книг;
- помощь с кодом без загрузки исходников во внешний сервис;
- работа с ИИ в дороге или без интернета;
- подготовка черновиков писем, планов, резюме и учебных материалов.

#### Пример: запуск модели через Ollama

После скачивания и установки [Ollama](https://ollama.com/) можно запустить китайскую модель Qwen одной командой через терминал*:

```
ollama run qwen2.5:7b
```

Она установится у вас на компютере локально и вы сможете в ней работать без интеренета и без риска утечки данных.
*— *если не знаете как это сделать, скопируйте абзац целиком, отдайте в любой ИИ и попросить написать вам подробную инструкцию по установке (в зависимости от вашего устройства и операционной системы)*

Также можно попробовать другие модели:

```
ollama run deepseek-r1:8b
ollama run qwen2.5-coder:7b
ollama run gemma3:4b
```

Ollama — это инструмент для запуска. Qwen, DeepSeek, Gemma и другие — сами языковые модели. Для коммерческого и корпоративного использования всегда стоит отдельно проверять лицензию выбранной модели.

## Как скачать опенсорс модель для локального использования

#### Сначала важное различие

<aside>
<img src="https://app.notion.com/icons/arrow-turn-right_gray.svg" alt="https://app.notion.com/icons/arrow-turn-right_gray.svg" width="40px" />

Скачать ИИ-модель с Hugging Face — не то же самое, что скачать приложение ChatGPT или Claude.

**ChatGPT Desktop и Claude Desktop** — готовые приложения с понятным интерфейсом: открыли окно, вошли в аккаунт и сразу начали диалог. Как правило, сами модели при этом работают в облаке разработчика.

**Модель с Hugging Face** — это набор файлов с «мозгами» ИИ: весами модели, её настройками и описанием. Сама по себе она не открывается как чат. Для работы ей нужна программа-запускатель, например **Ollama**. Она устанавливает модель на компьютер и даёт интерфейс для диалога с ней.

</aside>

```
Hugging Face → файлы модели → Ollama → локальный чат с ИИ
```

#### Как это сделать без терминала

Ниже — пользовательский сценарий для macOS и Windows на примере китайской модели **Qwen**.

**установите Ollama**

1. Откройте сайт [ollama.com](https://ollama.com/).
2. Выберите версию для macOS или Windows.
3. Скачайте установочный файл и откройте его.
4. Следуйте обычным шагам установки: перетащите приложение в папку «Программы» на Mac или подтвердите установку в Windows.
5. Откройте Ollama через Launchpad, меню «Пуск» или папку приложений.

В актуальных версиях Ollama есть графическое окно: в нём можно выбирать модели, скачивать их и вести диалог — без командной строки.

---

#### Самый простой путь: выбрать модель внутри Ollama

*При скачивании Ollama она предлагает несколько готовых можелей, которые даже не надо скачивать с huggingface*

Этот вариант лучше подходит для первого знакомства.

1. Откройте Ollama.
2. В окне нового чата нажмите на выбор модели — обычно это название текущей модели или кнопка наподобие **Select model / Choose model**.
3. В поиске введите `Qwen`.
4. Выберите модель, например **Qwen 2.5 7B Instruct**.
5. Нажмите **Download / Скачать**.
6. Дождитесь завершения загрузки.
7. Выберите модель и напишите первый запрос, например:*«Составь структуру еженедельного отчёта агронома».*

После загрузки Qwen будет работать на компьютере локально. Для последующих диалогов интернет обычно не нужен.

---

#### Если хочется выбрать модель именно на Hugging Face

Hugging Face полезен, когда нужно самостоятельно выбрать точную версию модели: её размер, язык, лицензию или степень сжатия.

1. Откройте сайт [Hugging Face](https://huggingface.co/).
2. В строке поиска введите `Qwen 2.5 7B Instruct GGUF`.
3. Откройте страницу модели от официального автора Qwen: [Qwen2.5 7B Instruct GGUF](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct-GGUF).
4. Прочитайте раздел с описанием модели и лицензией.
5. Перейдите во вкладку **Files and versions**.
6. Выберите файл формата `.gguf`. Для обычного ноутбука разумная стартовая версия — вариант с названием `Q4_K_M`: он обычно даёт хороший баланс качества, скорости и размера.
7. Нажмите кнопку скачивания и сохраните файл в отдельную папку, например «ИИ-модели» в «Документах».

Файл модели может занимать несколько гигабайт. Не стоит сохранять его в папку «Загрузки», если затем планируется чистить её: лучше сразу выбрать постоянное место.

#### Как добавить скачанную модель в Ollama

В некоторых актуальных версиях Ollama в управлении моделями есть действие наподобие **Import local model / Import model / Добавить локальную модель**.

1. Откройте Ollama.
2. Перейдите в раздел управления моделями или в настройки.
3. Выберите импорт локальной модели.
4. Укажите скачанный файл `.gguf`.
5. Дайте модели понятное имя, например `Qwen локальная`.
6. Дождитесь подготовки модели.
7. Создайте новый чат и выберите её в списке моделей.

Важно: интерфейс Ollama развивается, поэтому название кнопок и расположение раздела могут немного отличаться между версиями macOS и Windows.

Если в установленной версии нет пункта импорта локального файла, не нужно усложнять задачу терминалом: для начинающего пользователя лучше скачать Qwen прямо из каталога Ollama. Hugging Face в этом случае можно использовать как каталог для изучения моделей, их описаний и лицензий.

---

#### Как выбрать подходящий размер модели

Для первого опыта не стоит начинать с самой большой модели.

- **3B–4B** — лёгкие модели: быстрее скачиваются и подходят для несложных задач.
- **7B–8B** — хороший стартовый вариант для личного компьютера: Qwen 2.5 7B относится к этой категории.
- **14B и больше** — могут давать более качественные ответы, но требуют заметно больше оперативной памяти и места на диске.

Если модель отвечает слишком медленно или компьютер начинает заметно тормозить, лучше выбрать меньший вариант.

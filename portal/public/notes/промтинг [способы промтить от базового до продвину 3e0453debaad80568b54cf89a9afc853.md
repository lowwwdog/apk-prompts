# промтинг [способы промтить от базового до продвинутого]

## 1. Few-shot: учим модель на примерах

Суть: вы не просто объясняете, что нужно сделать, а показываете несколько образцов «вход → правильный результат». Модель считывает закономерность и применяет её к новому случаю.

Как это работает: примеры задают формат ответа, терминологию и правила классификации. Чем ближе новые данные к показанным примерам, тем надёжнее результат.

Когда полезно в АПК: привести данные из разных источников к единому виду, классифицировать культуры, типы рисков, обращения или статьи затрат.

Что важно:

- Использовать 2–4 понятных и типичных примера.
- Показывать разные варианты, а не почти одинаковые случаи.
- Ясно указать, что именно нужно вернуть: только категорию, таблицу или нормализованное название.

Простая формула:

```
Задача + несколько примеров «вход → результат» + новый случай + формат ответа
```

примеры

```jsx
Приведи названия сельскохозяйственных культур к единому формату.

Примеры:
«пшеница озимая» → «Пшеница озимая»
«ЯРОВОЙ ЯЧМЕНЬ» → «Ячмень яровой»
«кукуруза зерно» → «Кукуруза на зерно»

Новая запись: «подсолнечник масличный».

Верни только нормализованное название.
```

```jsx
Определи, к какому направлению АПК относится описание.

Примеры:
«Выращивание картофеля на открытом грунте» → «Растениеводство»
«Откорм молодняка крупного рогатого скота» → «Животноводство»
«Хранение и сушка зерна после уборки» → «Хранение и переработка»

Описание: «Производство комбикорма для молочных ферм».

Верни только направление.
```

```jsx
Классифицируй хозяйственный риск.

Примеры:
«Задержка поставки семян перед посевной» → «Логистический риск»
«Недостаток влаги в период вегетации» → «Агроклиматический риск»
«Рост цены на дизельное топливо» → «Финансовый риск»

Ситуация: «Поломка зерноуборочного комбайна в разгар уборки».

Верни только категорию риска.
```

## 2. Анализ по шагам: задаём рабочий алгоритм

Суть: модель получает не только задачу, но и последовательность проверки. Это помогает не пропустить важный этап анализа и делает ответ прозрачнее для человека.

Как это работает: вы задаёте маршрут — что сравнить, что посчитать, какие выводы допустимы, а какие требуют дополнительной проверки. Модель следует этому алгоритму и оформляет результат.

Когда полезно в АПК: анализ план–факт, подготовка к сезону, проверка производственных показателей, разбор отклонений урожайности или надоев.

Что важно:

- Описывать шаги коротко и в естественном рабочем порядке.
- Просить отделять факты от возможных причин.
- Заранее определить формат результата: таблица, список рисков, краткий вывод.

Простая формула:

```
Задача + алгоритм проверки + исходные данные + формат результата
```

примеры

```jsx
Проанализируй готовность хозяйства к началу посевной кампании.

Алгоритм:
1. Выдели ресурсы, которые уже готовы.
2. Найди дефициты и риски.
3. Определи, что может остановить старт работ.
4. Предложи последовательность первоочередных действий.

Данные:
Семена закуплены на 80%.
Техника прошла обслуживание на 60%.
Дизельное топливо закуплено полностью.
Агрономический план утверждён.
Не заключён договор на ремонт двух тракторов.

Верни таблицу: направление | текущая ситуация | риск | рекомендуемое действие.
```

```jsx
Проанализируй результаты уборочной кампании.

Алгоритм:
1. Сравни план и факт по площади, урожайности и валовому сбору.
2. Рассчитай отклонения.
3. Отдели факты от возможных причин.
4. Сформулируй вопросы, которые нужно уточнить у специалистов.

Данные:
Пшеница: план 1 000 га, факт 950 га; плановая урожайность 38 ц/га, фактическая 34 ц/га.
Ячмень: план 400 га, факт 400 га; плановая урожайность 32 ц/га, фактическая 35 ц/га.

Верни краткий аналитический вывод и таблицу отклонений.
```

```jsx
Проанализируй ситуацию на молочной ферме и предложи точки для проверки.

Алгоритм:
1. Сравни показатели с прошлым периодом.
2. Выдели значимые отклонения.
3. Не называй причины установленными фактами, если данных недостаточно.
4. Предложи, какие данные нужно запросить дополнительно.

Данные:
Средний надой на корову: 28 л в день, месяц назад — 31 л.
Расход корма на голову: без изменений.
Численность дойного стада: без изменений.
Средняя температура в коровнике выше обычной на 4 °C.

Верни: наблюдения, возможные факторы, данные для проверки, следующие шаги.
```

## 3. Reasoning: ставим цель и критерии решения

Суть: модель не ищет один «правильный» ответ, а помогает проработать решение по заданным критериям. Это подход для задач, где нужно выбрать приоритет, спроектировать процесс или сравнить варианты.

Как это работает: цель показывает, какого результата нужно достичь; критерии объясняют, по каким признакам оценивать варианты. Модель использует их как рамку для анализа и предложений.

Когда полезно в АПК: планирование сезона, приоритизация рисков, выбор направлений развития, разработка управленческого отчёта или регламента.

Что важно:

- Формулировать цель через результат: «снизить риск срыва посевной», а не «подумать о посевной».
- Добавлять 3–5 критериев: сроки, риски, ресурсы, экономика, применимость.
- Не просить выбрать единственный вариант, если не хватает данных конкретного хозяйства.

Простая формула:

```
Цель + исходные условия + критерии оценки + ожидаемый формат решения
```

примеры

```jsx
Составь план снижения рисков для растениеводческого хозяйства перед сезоном.

Цель: обеспечить своевременное проведение весенне-полевых работ.

Условия:
Хозяйство обрабатывает 3 000 гектаров.
Основные культуры: пшеница, подсолнечник, кукуруза.
Есть риски задержки поставок, погодных ограничений и поломок техники.

Критерии:
— действия должны быть реалистичны для среднего хозяйства;
— приоритет — предотвращение остановки работ;
— для каждого риска нужны превентивная мера и план реагирования;
— не предлагай конкретных поставщиков или неподтверждённые цифры.

Верни таблицу: риск | вероятность | влияние | профилактика | действие при наступлении риска.
```

```jsx
Предложи структуру еженедельного отчёта для руководителя агропредприятия.

Цель: за пять минут видеть ход сезона, ключевые отклонения и решения, которые нужно принять.

Критерии:
— отчёт должен подходить для растениеводства и животноводства;
— различай факт, прогноз и риск;
— не перегружай отчёт второстепенными показателями;
— для каждого риска указывай требуемое управленческое решение.

Верни шаблон отчёта с разделами, полями и краткими правилами заполнения.
```

```jsx
Разработай критерии выбора культуры для включения в севооборот хозяйства.

Цель: принять предварительное управленческое решение до детального экономического расчёта.

Критерии оценки:
— соответствие климату и почвам;
— влияние на севооборот;
— потребность в технике и ресурсах;
— потенциальный рынок сбыта;
— производственные и финансовые риски.

Сначала предложи набор критериев с пояснениями, затем покажи пример сравнения трёх культур: соя, подсолнечник, ячмень.

Не утверждай, что одна культура лучше другой без исходных данных конкретного хозяйства.
```

## 4. Контекст: даём материалы и границы работы

Суть: модель работает не «вообще про АПК», а с конкретными материалами: таблицами, заметками, регламентами, отчётами. Одновременно вы задаёте границы — на что она может опираться и каких действий или выводов делать не должна.

Как это работает: контекст становится источником фактов, а ограничения снижают риск выдуманных данных и чрезмерно уверенных выводов. Модель собирает, структурирует и анализирует только предоставленную информацию.

Когда полезно в АПК: подготовка аналитической записки, сводки для совещания, предварительный разбор производственных данных, работа с внутренними регламентами и документами.

Что важно:

- Вставлять только материалы, действительно нужные для задачи.
- Указывать: «используй только приведённые данные».
- Просить отмечать нехватку данных, гипотезы и вопросы для уточнения.
- Не поручать модели окончательные ветеринарные, агрономические, юридические или финансовые решения без профильной проверки.

Простая формула:

```
Роль + контекст и материалы + задача + ограничения + формат результата
```

```jsx
Ты аналитик агропредприятия.

Ниже будет набор материалов: производственные показатели, заметки агронома и данные о погоде.

Задача:
1. Составить краткое резюме ситуации.
2. Выделить подтверждённые факты.
3. Отдельно указать риски и гипотезы.
4. Сформулировать вопросы для следующего совещания.

Ограничения:
— используй только данные из предоставленных материалов;
— не подменяй гипотезы фактами;
— если данных недостаточно, прямо укажи это;
— не делай юридических, ветеринарных или агрономических заключений вместо профильного специалиста.

Материалы:
[вставьте документы, таблицу или заметки]
```

```jsx
Ты помощник руководителя сельскохозяйственного предприятия.

Контекст:
Предприятие занимается растениеводством, хранением зерна и продажей продукции.
Ниже приведены рабочие заметки нескольких подразделений.

Задача:
Подготовь проект повестки управленческого совещания на 30 минут.

Формат:
— вопрос;
— краткий контекст;
— какое решение требуется;
— ответственная роль;
— ожидаемый результат.

Ограничения:
— не назначай конкретных сотрудников;
— не придумывай показатели и факты;
— при нехватке данных сформулируй вопрос для уточнения.

Заметки подразделений:
[вставьте заметки]
```

```jsx
Ты готовишь черновик аналитической записки по развитию хозяйства.

Контекст:
Ниже будут приведены сведения о землях, культурах, технике, урожайности, каналах сбыта и ограничениях.

Задача:
Выдели три возможных направления развития предприятия на ближайшие два года.

Для каждого направления укажи:
— какую проблему или возможность оно использует;
— какие ресурсы потребуются;
— ожидаемый эффект;
— риски и допущения;
— какие данные нужно дополнительно проверить перед решением.

Ограничения:
— не выдавай прогнозы за гарантированный результат;
— не используй внешние данные, если они не приложены;
— не предлагай действия, требующие незаконного или небезопасного использования ресурсов.

Исходные данные:
[вставьте материалы]
```

---

Главное различие подходов:

| Способ | Что даём модели | Для чего подходит |
| --- | --- | --- |
| Few-shot | Готовые образцы | Повторяющиеся типовые задачи |
| Анализ по шагам | Алгоритм проверки | Разбор данных и отклонений |
| Reasoning | Цель и критерии | Выбор и проектирование решений |
| Контекст | Материалы и ограничения | Работа с конкретной рабочей ситуацией |

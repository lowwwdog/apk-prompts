# АПК · Готовые промпты по кейсам проекта

Подготовлено 19 сентября 2026 года. 40 кейсов × 3 сервиса = 120 самостоятельных промптов.

Основа — таблица «Идеи As is / To be», вкладка «Лист1», строки 2–98: 97 записей участников и фасилитатора. Повторы объединены, для каждой записи есть соответствие в карте покрытия. Других содержательных файлов в локальной папке проекта не было. Исходные фотографии не предоставлены: точность их расшифровки не подтверждена. Сценарии и критерии проверки ниже — разработанные предложения, а не дословные требования участников.

## Как пользоваться

1. Выберите кейс и один сервис. Каждый блок самостоятельный: общую инструкцию отдельно приклеивать не нужно.
2. Замените поля в квадратных скобках и приложите указанные материалы. Если данных пока нет, промпт поможет уточнить задачу, но реальный результат без них не гарантирован.
3. ChatGPT используйте для разового разбора, текста и работы с приложенными материалами; варианты Codex и Claude Code ориентированы также на файлы, проверяемые расчёты и повторяемый запуск. Это редакционный способ распределения задач, а не жёсткое ограничение возможностей продуктов.
4. Для Codex/Claude Code откройте отдельную рабочую папку с разрешёнными копиями входных файлов. Для конфиденциальных задач используйте синтетический набор, пока передача данных не разрешена. Локальный клиент не равен локальной обработке моделью.
5. Проверяйте результат по критериям в самом промпте. Наличие красивого ответа не подтверждает правильность расчётов или готовность интеграции.

Промпты подготовлены и проверены на полноту формулировок; их выполнение на реальных рабочих данных в трёх сервисах не тестировалось. Доступ к файлам, поиску, созданию артефактов и интеграциям зависит от конкретной среды. Сборник не устанавливает навыки и не запускает автоматизации.
